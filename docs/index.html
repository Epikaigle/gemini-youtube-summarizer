Simple par conception

YouTube → Résumer → Gemini.

C’est tout. L’extension automatise seulement les étapes répétitives.

01

Choisissez votre vidéo

Le bouton Résumer est disponible sur la page de lecture et dans les menus YouTube compatibles.

02
✦

Cliquez sur Résumer

L’extension associe automatiquement l’URL de la vidéo à votre consigne personnalisée.

03
✦

Gemini prend le relais

Gemini s’ouvre, le prompt est injecté et l’envoi de la demande est tenté automatiquement.

Votre prompt, votre façon de travailler

Demandez exactement ce dont vous avez besoin.

« Résume-moi la vidéo », « donne-moi les idées clés », « explique comme à un débutant »… Le texte placé avant le lien YouTube est entièrement personnalisable.
