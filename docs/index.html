2 Prompt envoyé
Simple par conception

De YouTube à Gemini
sans copier-coller.

L’extension automatise uniquement les étapes répétitives. Vous gardez le contrôle : rien ne part tant que vous ne cliquez pas sur Résumer.

01

Choisissez une vidéo

Sur YouTube, l’action Résumer s’intègre aux menus et à la page de lecture.

02

Cliquez sur Résumer

L’URL de la vidéo est normalisée et associée à votre texte de prompt personnalisé.

03

Gemini prend le relais

Gemini s’ouvre, le prompt est injecté et l’envoi est tenté automatiquement.

Pensée pour aller vite

Le raccourci qui manquait à YouTube.

Pas de tableau de bord, pas de compte supplémentaire, pas de serveur intermédiaire.

Intégration native à YouTube

Le bouton apparaît directement là où vous regardez vos vidéos, y compris sur la page de lecture et dans les menus compatibles.

Aa

Prompt personnalisable

Remplacez « Résume-moi la vidéo : » par votre propre consigne, ou laissez le champ vide pour envoyer uniquement le lien.

↗

Ouverture automatique de Gemini

L’extension prépare le prompt, ouvre Gemini et tente de lancer la demande sans copier-coller manuel.

◉

Minimaliste et transparent

Aucune télémétrie, aucun cookie ajouté, aucun historique envoyé à un serveur du développeur. Le code est public sur GitHub.

Vie privée

Vos vidéos ne passent pas par nos serveurs.

L’extension ne possède aucun serveur de collecte. Au clic, elle transmet à Gemini l’URL de la vidéo choisie et, si vous en avez défini un, votre texte personnalisé. Rien n’est envoyé au développeur.

Tester l’extension

Installation manuelle dans Firefox.

Cette méthode charge l’extension temporairement pour la tester. Firefox 140 ou une version plus récente est requis sur ordinateur.

Télécharger le projet
  1. 1
    Décompressez le projet

    Téléchargez l’archive puis extrayez-la dans un dossier.

  2. 2
    Ouvrez about:debugging

    Dans Firefox, rendez-vous sur about:debugging#/runtime/this-firefox.

  3. 3
    Chargez l’extension

    Cliquez sur « Charger un module complémentaire temporaire », puis choisissez manifest.json.

  4. 4
    Ouvrez YouTube

    Actualisez YouTube : le bouton Résumer est prêt à être utilisé.
